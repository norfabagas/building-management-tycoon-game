# Building Management Tycoon runtime assets

158 PNG/WAV files plus `manifest.json`, with the defined BM identity and approved artwork family. These folders are bundled locally for Android/Web through `pubspec.yaml`.

Usage, animation frame order, pivots and coverage: [docs/Assets.md](../../docs/Assets.md).

Reproducible exporters, editable SVG sources, reference-guided character sheets, original audio synthesis, contact sheets and the interactive gallery: [design/production](../../design/production/README.md).

The manifest identifies original sources and checksums. Do not infer gameplay capacity, prices, road width or unlocks from illustration geometry. Future malls/VIPs are outside this pack. Engine animation, building/road composition and audio playback remain gameplay implementation work.
