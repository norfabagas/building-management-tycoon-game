# Full-area mobile map and smooth rotation

The 2026-10-18 user follow-up asks for a map covering almost the whole mobile/small screen and smooth rotation, including the two-finger twisting behavior of map applications. This supersedes the earlier in-flow mobile map/panel split in CameraAndActions.md and MobileReachability.md. Existing approved cream/evergreen controls, assets and BM branding remain authoritative.

## Layout decisions

When the viewport is narrower than 700px or shorter than 500px, the district overview and building footprint drawing use the entire SafeArea as the map canvas. The map sits behind compact floating HUD/navigation cards rather than losing its height to the app bar, large stat blocks or a permanent welcome panel. A Back control, district name, balance/day/clock/gems and audio remain in the top card. Stats scroll horizontally when text/amounts exceed the available space. The bottom card retains the scrollable Build/Tenants/Upgrades/Finances controls and fixed District activities menu. All interactive targets remain at least 48px. Existing Web footer clearance remains below the floating actions, with the map continuing behind it rather than an empty layout reservation.

Compass/Main road controls sit below the floating HUD; zoom sits above the floating action card and shifts left in shallow viewports so it cannot overlap the compass/road controls. Building opening shortcuts sit above zoom/actions. The old instructional banner is omitted in this mode to avoid obscuring land. Financial/directory/collection views open as deliberate scrolling overlays with Close; closing them restores the uninterrupted map and preserves horizontal navigation scroll. Decorations placement keeps its established dedicated layout. Building interiors, type selection and final cost review keep their full content layouts with pinned actions. Larger desktop layouts retain the side panel and existing HUD.

Footprint drawing retains the full map with a compact floating floor stepper, footprint dimensions, Review cost, Close and Plan details. Plan details expands the existing quote/capacity/road/upkeep information over the HUD to recover scroll space on short landscape; Back to map collapses it. The fixed Review cost action is not duplicated inside expanded details. Confirm/cancel/redraw remain in the existing full-area review. These views do not change the selected footprint, initial floor count or camera. The map may be partially covered by intentional overlays, but its viewport is not resized by the mobile HUD or drawing bar. Changing between an interior/review and map can recreate the painter/ticker; the shared session camera remains authoritative.

## Rotation and gesture decisions

Existing two-pointer scale/rotation/pan remains a direct per-event transform anchored to the actual focal world point. It does not add tween lag or snapping to the fingers. Keep the multi-touch preview restoration and suppression of accidental drawing/selection until all fingers lift. Rendering, depth, picking, roads and actors use the same rotated projection.

Compass Rotate left/right now animates 90 degrees over 320ms with easeInOutCubic. Reset rotation takes the shortest angular route to the original bearing. Each animation frame uses the existing focal camera transform so the centre world point stays fixed and zoom is unchanged. A new command starts from the currently displayed bearing. Touch/pan/pinch, zoom, Main road or Center map interrupts an in-progress turn before applying its own movement, avoiding delayed camera jumps. Reduced-motion settings apply the requested bearing immediately. Animation state and tickers belong to DistrictMap presentation; no domain/save fields or dependencies are added.
